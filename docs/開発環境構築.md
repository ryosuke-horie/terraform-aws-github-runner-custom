4. Lambdaのバイナリをインストール

```bash
cd lambdas-download
# OSS公式のリリースページを参照して最新のバイナリをインストール(実行時は5.20.0が最新)
# https://github.com/philips-labs/terraform-aws-github-runner/releases
wget https://github.com/philips-labs/terraform-aws-github-runner/releases/download/v5.20.0/webhook.zip
# 上記のようにzipファイルをすべてダウンロードする
```
