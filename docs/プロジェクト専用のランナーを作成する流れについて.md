作成方法については以下のドキュメントを参照してください。

- [packerによるamiのビルド方法](/docs/packerによるamiのビルド方法.md)
- [カスタムAMIの実装について](/docs/カスタムAMIの実装について.md)

## 2. TerraformでGitHub Runnerのプロジェクト専用設定を行う

以下の手順で設定を行います。

1. `main.tf`の`multi_runner_config`にプロジェクト専用の設定を追加します。
    - `matcherConfig`, `labelMatchers`にプロジェクト名を指定します。
    - amiフィルターの指定をPackerで生成したAMIを参照できるように設定します。
2. terraform applyで設定を反映します。

3. GitHubのオーナー権限のアカウントでGitHub Appsの設定ページを開き、`mits-terraform-aws-github-runner`のconfigureを開きます。
    - Repository accessにプロジェクトを追加します。
4. GitHub Actionsのyamlファイルの`runs-on`にterraformで設定したラベルを指定します。
